# Claude Code Instructions

1. **Always read and follow `AGENTS.md` before doing any work.** For feature work, also read `docs/WORKFLOW.md` and the relevant files in `docs/features/`.
2. Treat `AGENTS.md` as the shared source of truth for repository workflow, documentation, verification, and commit style. Do not duplicate or override its instructions here.
3. **Do not add AI attribution to Git commits.** In particular, do not add `Co-Authored-By: Claude` (or similar AI co-author trailers), `Generated with Claude Code`, or other AI attribution lines to commit messages. Do not append such trailers automatically when generating commits.
4. Follow the human approval gates in `AGENTS.md`: approval of feature scope authorizes writing specs, **not** beginning implementation.
